- [安装直链](https://raw.githubusercontent.com/Jarv1s0/Logic/master/Loon/YouTube.lpx)。同一时间只启用一套处理相同请求的 YouTube 插件。
- 保留原播放去广告、后台播放、播放地区、首页 Shorts 隐藏、频道屏蔽与日志导出；合并 YouTube Clean 1.2.12 的广告模板、新首页容器处理、底栏控制和字幕模块。
- [固定版本、源码、许可与构建说明](../Script/YouTube/SOURCE.md)。

## 设置与使用

新增「隐藏底部发布按钮」和「隐藏底部 Shorts」，默认均关闭；它们独立于「隐藏首页 Shorts」。修改底栏设置后强制退出 YouTube 再打开，必要时刷新页面；脚本同时取消相关请求的条件缓存。

「字幕翻译」默认关闭。开启后，在 YouTube 打开 CC 并选择视频原语言字幕；目标语言支持简体中文、繁体中文、英语、日语与韩语。已有的 `zh-CN`、`en-US` 设置继续有效。「双语字幕」默认关闭，开启后原文在上、译文在下；「字幕智能换行」默认开启，只调整译文，不改变字体、位置或时间轴。

字幕支持 JSON3、SRV3、SRV1 和 WebVTT。常规情况下，收到原字幕后最多额外下载一次 YouTube 目标译文；下载限时 4 秒，字幕处理网络预算 6.5 秒，脚本超时 8 秒。翻译失败保留原字幕，遇到 HTTP 429 后按 `Retry-After` 暂停额外请求，范围为 30–300 秒。没有字幕时不能生成字幕；手动选中的其他翻译语言保持原样。不会转发 Cookie、Authorization，不跟随重定向，也不会调用 Google 备用翻译。

信息流补充图片、轮播、品牌与视频广告模板，以及字段 `474376530` 的新首页容器识别。匹配限制在已识别的模板和卡片结构，不按视频标题中的广告关键词删除内容。新容器共用 8192 节点、24 MiB 累计访问和 24 层深度预算，单节点最多 2048 字段；超过预算撤回当前容器的未完成修改。API 正文上限 8 MiB，字幕上限 1 MiB。服务端结构变化仍可能造成广告遗漏。

「播放请求地区」只修改客户端 `gl` 参数，不改变出口 IP；后台播放对直播和受限内容的效果仍由 YouTube 决定。频道屏蔽继续支持手动列表与每小时更新的远程列表。

日志及完整媒体采样默认关闭。关闭日志后，下次命中对应 API 会清除日志，需保留时先导出。完整媒体采样可能增加延迟；字幕与新过滤器只输出有限结构诊断，不记录字幕正文或签名 URL。普通媒体在关闭日志时不读取响应体，初始化 POST 仍使用原有空白视频重写。

## 验证边界与回滚

本地自动检查执行实际构建的分接口脚本，覆盖首页及分页广告混排、新容器、正常字节保留、预算回退、底栏独立开关、字幕格式与时间轴、失败回退、限流、超时/重复回调、频道屏蔽、后台播放、地区参数、日志生命周期、插件路由及产物校验。夹具为自写数据，不代表已取得用户真实广告响应。

未进行 Loon 真机验证，无法确认实际去广告、底栏显示、字幕显示和播放稳定性，也无法确认内存或延迟改善。真机验收应分别检查首页/分页广告、底栏开关、原文/译文/双语字幕和连续播放；字幕失败时应仍能看到原文。

新增显示功能可通过相应开关关闭。完整回滚需恢复本次修改前的插件配置；原两个脚本入口保持原样，旧配置引用仍可使用。
